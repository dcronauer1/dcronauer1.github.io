My Work

Hall Effect Sensor System

Python project to read data from TMAG5173 magnetic sensors
Details:
    Developed a Python system to read data from TMAG5173 Hall effect sensors. Data is sent from a MicroPython microcontroller to a Raspberry Pi via MQTT, stored in InfluxDB, and visualized in Grafana. The Raspberry Pi also sends commands back for motor control and other tasks.

YouTube Music Downloader

Discord bot to automate downloading and syncing music from YouTube
Details:
    Created a Discord bot that automates downloading and syncing music from YouTube. Built with Python, Discord.py, yt-dlp, and MusicBrainz, it supports playlists, custom metadata, retroactive updates, and automatic file syncing to devices via SSH.
